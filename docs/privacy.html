ALOFT — Privacy Policy

Last updated: 16 October 2026

1. Who we are

ALOFT (the "Application") is a private, single-user tool operated by the owner of the TikTok account @xaloftx. This policy describes how the Application handles data for that one user — its operator — because no other users exist.

2. Data the Application accesses

The Application uses the TikTok Content Posting API to upload videos to the operator's own TikTok account. To do that it requests the following TikTok scopes:

• user.info.basic — to identify the authenticated TikTok account.
• video.upload — to upload videos to the operator's own account (drafts/inbox).

No data about other TikTok users, their videos, their followers, or their activity is accessed.

3. How the data is used

The Application uses the access token only to upload videos the operator has produced. The access token is stored locally on the operator's own device (or in a private GitHub secret for the operator's own repository) and is used only to authenticate requests to TikTok's own API endpoints.

4. Data sharing

No data is shared with third parties. The Application does not transmit TikTok data to any service other than TikTok itself.

5. Data retention

Access tokens are kept only as long as needed for the Application to function. Tokens can be revoked at any time by the operator from TikTok's account settings or by deleting them from the device on which they are stored.

6. Cookies and tracking

The Application is not a website and does not use cookies, pixels, analytics, or any user-tracking technology.

7. Children

The Application is not directed to children. Only its operator — an adult — uses it.

8. Changes

This policy may be updated at any time. Material changes will be reflected by an updated "Last updated" date above.

9. Contact

Questions can be sent through TikTok direct message at @xaloftx.
